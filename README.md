# AWS Tech Showcase ☁️

Uma landing page de uma única página criada para apresentar, de forma visual e objetiva, cinco tecnologias da Amazon Web Services (AWS):

- **Amazon QLDB** — banco de dados ledger com histórico de alterações verificável.
- **Amazon QuickSight** — Business Intelligence para análises, dashboards e relatórios.
- **Amazon RDS** — serviço gerenciado para bancos de dados relacionais.
- **Amazon Redshift** — data warehouse para análise de dados em escala.
- **Amazon Timestream** — banco de dados especializado em séries temporais.

> **Nota sobre o QLDB:** o Amazon QLDB foi incluído porque faz parte do escopo do projeto. A AWS encerrou o suporte ao serviço em **31/07/2025**.

## ✨ Sobre o projeto

O objetivo é transformar um conjunto de tecnologias AWS em uma experiência simples, moderna e agradável de navegar, sem transformar a página em uma documentação extensa.

A interface utiliza:

- Hero section com animação visual;
- Cards individuais para cada tecnologia;
- Tags para destacar os principais conceitos;
- Destaque específico para o status histórico do QLDB;
- Seção final mostrando o fluxo **Dados → Armazenamento → Análise → Insights**;
- Layout responsivo para desktop, tablet e mobile;
- Animações leves usando JavaScript e CSS.

## 🚀 Como executar

Não é necessário instalar dependências.

1. Clone o repositório:

```bash
git clone https://github.com/SEU-USUARIO/aws-tech-showcase.git
```

2. Entre na pasta:

```bash
cd aws-tech-showcase
```

3. Abra o `index.html` no navegador.

Também é possível publicar diretamente no **GitHub Pages**.
